# 墨阅 MoRead · 静态前端 Demo

毕业设计「个性化阅读平台」的第一阶段设计稿。纯静态页面，无需后端、无需联网，所有素材已本地化。

## 如何打开

方式一：直接双击 `index.html`（推荐 Chrome / Edge）。

方式二：在本目录启动一个本地服务器，交互与截图更稳定：

```bash
cd demo
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

## 可以试的交互

- 按 `/` 或 `Ctrl/Cmd + K` 打开全局搜索。
- 首页书脊悬停会抬起并显示提示，点「换一批」切换书架。
- 首页：点编辑书单进入书单筛选；书库会显示书单横幅。
- 书库：分类筛选、搜索、排序、网格 / 列表切换、仅免费。
- 书籍详情：切换目录 / 书评，提交书评（保存在本机）；书架按钮可标记想读 / 在读 / 读完或移出。
- 阅读器：
  - 顶部「目录 / 笔记 / 统计」打开抽屉；
  - 「字号 / 主题」调整排版，设置会被记住；
  - 选中正文文字，会出现「划线 / 记笔记 / 复制」工具条；
  - 从书架点「继续阅读」会带 `?resume=1`，回到上次进度。
- 书架：切换分类、悬停移除、查看本周阅读数据表。
- 共读：按话题筛选、点赞、发起讨论；点评论数打开回应弹窗，可继续回复。
- 个人中心：查看阅读目标圆环，调整年度目标；阅读偏好与热力图。
- 管理后台：切换五个面板；新增图书会出现在表格顶部；用户状态可切换；书评可按状态筛选并审核；拖动推荐权重，右侧 Top 6 和公式实时变化，保存后会记住。
- 登录页：注册模式会显示昵称；使用演示账号登录；`admin@moread.cn` 会进入后台。

## 设计方向

「书房索引」：松绿书布、绛红印章、铜色细节、冷调纸面；竖排书脊、索引式分隔线、编辑型排版。刻意避开常见的「米色 + 大衬线 + 陶土色」模板感，也避免统一圆角卡片 + 阴影的 SaaS 风格。

- 字体：正文 Noto Sans SC / 微软雅黑；标题 Noto Serif SC / 华文中宋 / 宋体；批注与引文楷体。
- 色板：纸 `#E9EAE2`、墨 `#17211D`、松 `#24443A`、绛 `#8C3A32`、铜 `#A98B4F`。
- 动效：只在首屏书脊入场和用户操作时出现，尊重 `prefers-reduced-motion`。
- 可访问性：键盘焦点可见、表单有标签、图表有数据表、插画有替代文本、深浅色主题均校验对比度。

## 数据说明

- 书籍、用户、书评、帖子、统计数据均为**演示数据**。
- 收录的公版经典（鲁迅、老舍、萧红、沈复等）只使用书名、作者与简介，不包含正文。
- 阅读器正文《灯下》为项目原创演示文本，不属于任何出版物。
- 正式版接入授权内容或站内原创稿件后替换。

## 已知限制

- 纯静态：无真实登录、无数据库、无接口；刷新后部分操作（如发帖）不保留。
- 阅读统计为前端估算（本次阅读时长、本书进度、笔记 / 划线数量），正式版由后端事件表汇总。
- 推荐权重面板用演示分数模拟，用于展示算法交互；正式版由后端离线任务产出。
- 书单、评论、阅读目标、后台新增图书均为前端演示；评论与目标保存在本机浏览器。
- 书籍封面由 CSS 生成，正式版可替换为出版社授权封面或站内原创封面。
