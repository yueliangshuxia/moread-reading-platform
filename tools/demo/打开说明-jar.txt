墨阅 MoRead · 本地演示版

一、怎么打开
1. 解压整个文件夹（不要在压缩包里直接双击）
2. 双击“run.bat（启动墨阅）”
3. 浏览器会自动打开 http://127.0.0.1:8080/
   如果没有自动打开，手动在浏览器输入上面的地址

二、演示账号
读者：reader@moread.cn / 123456
管理员：admin@moread.cn / admin123
管理员登录后会进入后台。

三、数据说明
- 演示版使用内嵌 H2 数据库，不需要安装 MySQL
- 数据保存在 data/ 文件夹
- 想恢复初始数据：关闭“墨阅服务”窗口，删除 data/ 文件夹，再重新启动

四、常见问题
- 提示找不到 Java：安装 Java 21，或改用“免安装版”（自带运行时）
- 8080 端口被占用：关闭占用程序，或用命令行启动：
  java -jar moread-server.jar --spring.profiles.active=demo --server.port=8081
  然后访问 http://127.0.0.1:8081/
- 页面暂时打不开：第一次启动要初始化演示数据，等 10-20 秒刷新
